## 💻 Prerequisites

Before you begin, make sure your device meets the following requirements:

### ⚙️ Development Environment & Tools
- **Operating System:** Windows 10+ / macOS / Linux
- **IDE:** [Eclipse IDE for Enterprise Java and Web Developers](https://www.eclipse.org/downloads/packages/) (2023-x or higher recommended)
- **Java Development Kit:** [JDK 17 or JDK 21](https://www.oracle.com/java/technologies/downloads/) (Ensure `JAVA_HOME` is set in your system environment variables)
- **Build & Dependency Tool:** [Apache Maven](https://maven.apache.org/) (Built into Eclipse, or standalone v3.8+)

### 🗄️ Database Server
- **Database:** [MySQL Community Server v8.0 or higher](https://dev.mysql.com/downloads/mysql/)
- **Database GUI Client:** [MySQL Workbench](https://dev.mysql.com/downloads/workbench/)

### 🔌 Drivers & Dependencies
- **JDBC Driver:** This project uses **Apache Maven** for dependency management. Downloading the MySQL JDBC driver manually is not necessary.
